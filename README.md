# AI Image Caption Generator

A simple web interface built using Gradio and Salesforce BLIP (`Salesforce/blip-image-captioning-base`) to automatically generate captions for uploaded images.

## Features
- End-to-end pipeline using Hugging Face `transformers`
- Interactive web UI using `gradio`
- Local or hosted inference support
